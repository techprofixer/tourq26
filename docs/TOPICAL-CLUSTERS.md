# Torq Studio — Topical Cluster Map

Use this as the content backlog. Each **cluster** = 1 pillar page + supporting pages that all link to the pillar and to each other. Google (and AI answer engines) rank sites that cover a topic *completely*, so we finish one cluster before opening the next.

Companion docs: `SEO-GROWTH-PLAN.md` (strategy), `SEO-STRATEGY.md` (technical).

---

## How to use this

**Build order (do not spread thin):** Cluster 1 → 2 → 3 first. Each needs ~10–14 pieces. Finish a cluster (≈6–8 weeks at 2 pieces/week) before starting the next.

| Priority | Cluster | Why first |
|----------|---------|-----------|
| 1 | **Mobile app development (Gulf-focused)** | Existing UAE fintech case study; highest-intent buyers |
| 2 | **Custom CRM & business software** | Productised offer (`/solutions/build-crm`), cost queries convert |
| 3 | **AI chatbots & AI workflows** | KSA logistics AI case study; fast-growing demand |
| 4 | Hiring remote / dedicated engineers (India ↔ Gulf/EU) | Matches the "remote-it" service; vendor-choice queries |
| 5 | Web platforms, APIs & e-commerce replatform | DACH case studies |
| 6 | Compliance & regional (KSA/UAE/EU) | Cross-cuts all clusters, hard for competitors to copy |
| 7 | torqOS (product) | Separate funnel — plan after defining its category |

### Page types (map to the CMS)
| Label | CMS type / route | Role |
|-------|------------------|------|
| **PILLAR** | Service / Solution page, 2,000+ words | Ranks for the head term; hub of the cluster |
| **GUIDE** | Guide (`[...slug]`) or Blog | Informational, long-tail |
| **COST** | Guide | "How much does X cost" — highest conversion |
| **VS** | Comparison | "X vs Y" decision queries |
| **GLOSS** | Glossary term | Definitions, AI-citation bait; 300–600 words |
| **LOC** | Location page | Service × city, unique content only |
| **IND** | Industry page | Service × vertical |
| **CASE** | Case study | Proof; link from every relevant piece |
| **TOOL** | Freebie / calculator | Link magnet + leads |

### Rules for every piece
1. One primary keyword per URL; set it as the CMS **focus keyword**.
2. Links: piece → its **PILLAR** (descriptive anchor) · pillar → piece · piece ↔ 2–3 sibling pieces · piece → 1 **CASE** · piece → `/contact` or audit CTA.
3. Start with a **Key takeaways** block (2–5 answer-first lines), then a named author.
4. Include one original element: a real number, price range, screenshot, architecture diagram or checklist.
5. Add 4–6 FAQ items (FAQPage schema comes from the FAQ block).
6. Don't publish below a "good" score in the CMS SEO sidebar.

## Before you write

1. **Verify each target** in Search Console, Google autosuggest / People-also-ask or Ahrefs/Semrush. Drop or merge queries with no demand; I have not checked volumes.
2. **Mine sales calls and WhatsApp/chat logs** (Admin → Chat logs, Leads) for the real questions buyers ask — these beat keyword tools for bottom-funnel topics.
3. **Don't publish cost numbers you can't defend.** Use ranges from your own past quotes.
4. **Refresh quarterly**: update the numbers, bump `dateUpdated`, and re-submit via IndexNow (automatic on CMS publish).
