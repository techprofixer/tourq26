## 4. Angle and differentiation

1. **AED first**, USD in brackets. UAE reader thinks in AED.
2. **Costs competitors skip:** Arabic/RTL, UAE payment gateways (Tap, PayTabs, Telr, Apple Pay), UAE Pass login, VAT on development, app store fees, Emirates ID / KYC providers, hosting with UAE data residency, WhatsApp Business API fees.
3. **Team-location cost comparison:** same scope quoted with a Dubai agency, a Mumbai senior team (Torq's model), and a European agency. Ties into Cluster 4.
4. **Transparent estimator logic:** show what changes the price (features × platforms × integrations × compliance), not just a range.
5. **First-person evidence:** "from projects we've scoped…" with real, anonymised data once you can back it.
